# 使用说明

## 主菜单

1. 默认更新：使用保守规则更新。
2. 自定义更新：分别决定每一类差异的处理方式，也可逐项选择。
3. 恢复备份：列出当前旧配置文件的历史备份，恢复前会先备份当前文件。
4. 更换文件：输入旧配置与新配置的绝对路径；输入时支持 Tab 补全。

## 差异与默认策略

| 差异类型 | 默认处理 |
| --- | --- |
| 值冲突（同一节、同一键的值不同） | 保留旧值 |
| 新增配置项 | 添加到旧文件，并按新版配置中的位置插入 |
| 新版删除的旧配置项 | 保留旧项 |
| 新增节 | 添加整个节 |
| 新版删除的旧节 | 保留旧节 |

自定义更新可将每种类别设置为统一处理，或选择“逐项询问”。不存在的差异类别不会显示无效问题。

## 备份与恢复

每次真正写入前，程序都会在旧配置文件相同目录创建备份：

    settings.ini.bak.YYYYMMDD-HHMMSS

恢复备份时也会先为当前文件创建一份同样格式的备份，因此可继续恢复到更早状态。

## 运行

源码方式：

    python3 iniupdate.py

发布版方式（Linux ARM64 / 树莓派 aarch64）：

    chmod +x iniupdate
    ./iniupdate

程序在执行写入前会展示计划更改；仅输入 Y 才会应用，输入 N 或按 Ctrl+C 不会修改配置文件。

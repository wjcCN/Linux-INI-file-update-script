# Linux INI 文件更新工具

用于将新版 INI 配置中的新增内容合并到客户旧配置，并由用户决定如何处理冲突、删除项和节。

## 功能

- 默认保守更新：冲突保留旧值，新增配置和新增节加入，旧配置和旧节不因新版缺失而删除。
- 自定义策略：可按类别统一处理，或对每一个差异逐项选择。
- 新增配置按新版顺序插入，不是简单追加到节末。
- 保留旧文件中的注释、空行和未修改内容。
- 每次更新前自动生成 `原文件名.bak.时间戳` 备份。
- 支持选择并恢复历史备份；恢复前同样备份当前配置。
- 支持路径和备份文件名 Tab 补全。
- 在当前终端显示边框化的差异、计划修改和最终结果。

## 运行环境

- Linux ARM64（当前发布版为树莓派 aarch64 构建）
- Python 3.11 或兼容版本：仅运行源码时需要
- 配置文件写入权限，默认路径通常需要 sudo 权限

## 使用源码

```bash
python3 iniupdate.py
```

## 使用发布版程序

从 GitHub Release 下载 `iniupdate` 后：

```bash
chmod +x iniupdate
./iniupdate
```

## 默认配置路径

```text
客户旧配置：/opt/engconfig/settings.ini
新版配置：  /opt/engfur/engconfig/settings.ini
```

也可以在主菜单选择“更换文件”，输入两份配置文件的绝对路径。

## 注意事项

- 执行更新前会先显示全部计划修改，只有确认 `Y` 后才会写入文件。
- 更新后请保留自动生成的 `.bak.时间戳` 文件，便于恢复。
- 发布版是 Linux ARM64 程序，不能直接在 Windows 或 x86 Linux 上运行。
